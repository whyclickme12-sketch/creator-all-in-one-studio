API 연결

키는 이 브라우저의 localStorage에만 저장되고 어디로도 전송되지 않습니다. YouTube·Gemini 요청은 내 브라우저에서 구글로 바로 갑니다.

키 발급 5분 가이드

  1. YouTube Data API v3 — API 라이브러리에서 사용 설정 → 사용자 인증 정보 → API 키 만들기. 하루 10,000 유닛 무료(분석 1회 ≈ 5~10 유닛).
  2. Gemini API — Google AI Studio에서 Create API key. 무료 등급으로도 개인용은 충분합니다.
  3. 두 키를 위에 붙여넣고 연결 테스트 → 저장. 키가 없어도 샘플 버튼으로 모든 화면을 써 볼 수 있고, 프롬프트 복사로 ChatGPT·Claude에 붙여 쓸 수 있습니다.
